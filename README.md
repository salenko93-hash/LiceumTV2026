# LyceumTV 3.4.1 — Raspberry Pi 4

Адаптований пакет для **Raspberry Pi 4 Model B**, Raspberry Pi OS **64-bit Bookworm або Trixie**, рекомендовано 4 GB RAM. Основний TV: 1920×1080, 60 Hz, порт micro-HDMI **HDMI0** (ближче до USB-C). Python backend і всі функції слайд-шоу збережені.

- SSH: `admin@192.168.2.193`
- TV: `http://192.168.2.193:8080/`
- Admin: `http://192.168.2.193:8080/admin`
- Ops: `http://192.168.2.193:8080/ops`
- Mobile: `http://192.168.2.193:8080/mobile/`

## Підготовка Pi

Через Raspberry Pi Imager встановіть Raspberry Pi OS 64-bit, створіть користувача `admin` з власним паролем, увімкніть SSH. Закріпіть `192.168.2.193` у DHCP на роутері. Скрипт не змінює мережеву конфігурацію Pi і не задає пароль. Потрібні Internet для apt, sudo та HDMI-телевізор з підтримкою Full HD 60 Hz. Використовуйте штатний KMS-драйвер (`dtoverlay=vc4-kms-v3d`), не legacy/FKMS; чистий образ Raspberry Pi OS рекомендований.

## Встановлення з Windows

Розпакуйте весь ZIP. У PowerShell у папці проєкту:

```powershell
python .\VERIFY_PROJECT.py
.\INSTALL_TO_RPI4.ps1 -NoReboot
```

SSH/SCP можуть попросити пароль користувача `admin`; sudo теж може попросити його в терміналі. Це пароль ОС, не ключ вебадмінки. Перевіряйте SSH fingerprint при першому підключенні. Installer запускає backend, але кіоск і новий HDMI-режим остаточно перевіряються після reboot:

```powershell
ssh admin@192.168.2.193 "sudo reboot"
# Після повторного завантаження:
.\CHECK_RPI.ps1
.\OPEN_ADMIN.ps1
```

Без `-NoReboot` Windows installer перезавантажує Pi автоматично. Параметри `-PiHost` і `-PiUser` дозволяють інше SSH-підключення; адресу Mobile/QR у такому разі змініть в адмінці.

## Ключ вебадмінки

`admin` — ім'я користувача Linux/SSH. Вебадмінка використовує окремий випадковий ключ. На Pi перегляньте його локально (не надсилайте у чат):

```bash
python3 -c 'import json; print(json.load(open("/opt/lyceumtv/data/config.json"))["admin_key"])'
```

Ключ вводиться у вебадмінці. Під час оновлення наявні ключі зберігаються.

## Що змінено для Pi 4

- Перевірка моделі Pi 4, 64-bit ОС і підтримуваної версії до встановлення пакетів.
- KMS + Cage + Chromium; основний HDMI обмежений Full HD через kernel cmdline. Прискорення GPU збережене. Немає overclock, `--no-sandbox` чи вимкнення перевірки TLS.
- Резервна копія `cmdline.txt.lyceumtv-rpi4.bak` поряд з оригінальним `cmdline.txt`, повторний запуск не перезаписує її.
- PipeWire/WirePlumber для звуку в headless-сесії; окремий Chromium-профіль без keyring-запиту.
- Виправлено запис початкових налаштувань у `/opt`, версію deployment-скрипта, очікування готовності API та безпечне завантаження в окрему тимчасову папку.
- Адреса Mobile/QR і приклади оновлені на `192.168.2.193`.

Живі налаштування, розклади, медіа й ключі під час оновлення зберігаються. Збережений `mobile_public_url` автоматично не переписується: при перенесенні з іншої адреси змініть його в Admin на `http://192.168.2.193:8080/mobile/`.

Після уроків TV показує лише задану назву і фотографії, без назв файлів та лічильника. Вміст розкладів і контрольні суми не змінені.
